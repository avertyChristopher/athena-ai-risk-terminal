# Athena Screenshots Guide

Add screenshots under a future `docs/screenshots/` folder or in the GitHub
README once the UI is ready to present.

## Recommended Captures

1. Dashboard with `Run Athena Demo Portfolio`.
2. Demo Run Summary after a successful run.
3. Architecture page system map.
4. Portfolio Builder overview for the demo portfolio.
5. Market Data chart and coverage section.
6. Risk Monitor analysis.
7. P&L Attribution overview.
8. Reconciliation break register.
9. Limit Center breach workflow.
10. Reports Center generated risk pack.
11. AI Anomaly Center scan output.

## Capture Notes

- Use a desktop viewport first, then one mobile/tablet screenshot if clean.
- Make sure the backend is running before capturing API-connected screens.
- Prefer realistic demo data over empty states.
- Keep file names simple:

```text
dashboard-demo-run.png
architecture-system-map.png
portfolio-builder-overview.png
risk-monitor-analysis.png
reports-center-risk-pack.png
```

## README Placement

Use 2 or 3 screenshots in the root README:

- Dashboard demo run.
- Architecture system map.
- Reports or Risk Monitor output.

Keep the rest in this docs folder to avoid making the README too heavy.
